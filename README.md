# Millionaire Quiz

An Android quiz game in the style of the 15-question, million-pound TV show. You pick any subject; Claude writes every question live, and the lifelines are generated by further Claude calls.

## Run it

1. Open this folder in **Android Studio** (File → Open → `MillionaireQuiz`). Let Gradle sync; the first sync downloads Gradle 8.9, AGP 8.7.3 and the Compose libraries.
2. Pick a phone or emulator (Android 8.0 / API 26 or newer) and press **Run**.
3. In the app, tap **Settings**, paste a Claude API key (create one in the Claude Console), choose a model and save.
4. Type a subject, name your Phone-a-Friend, and play.

If Android Studio offers to upgrade the Android Gradle Plugin, it's safe to accept.

## Or build it on GitHub (no Android Studio needed)

The workflow in `.github/workflows/build.yml` builds the APK on GitHub's servers every time you push to `main`.

1. Create a new repository on GitHub and push this folder to it (include the hidden `.github` folder).
2. Open the repo's **Actions** tab and wait for "Build APK" to go green (about 5 minutes the first time).
3. On your phone, open `https://github.com/<you>/<repo>/releases/latest` and tap **MillionaireQuiz.apk**.
4. Android will ask you to allow installs from your browser; allow it, then install.

Every build is signed with the same key (`app/debug.keystore`), so new builds install over old ones. If a build fails, the error is in the Actions log.

## How it works

| Piece | What it does |
|---|---|
| `data/ClaudeClient.kt` | Calls the Messages API with `HttpURLConnection` + `org.json` (no networking libraries). Retries on rate limits / overload, turns API errors into readable messages. |
| `game/Prompts.kt` | All prompts. Questions come back as a JSON list of five (`question`, `correct`, `wrong[3]`, `explanation`); the app shuffles the options itself so the right answer isn't always B. |
| `game/Lifelines.kt` | Decides lifeline reliability locally, so they behave like the show: the friend and audience are dependable early and shaky near £1M. |
| `game/GameViewModel.kt` | Game state machine: choose → "final answer?" → locked in → reveal. Loads questions in batches of five and fetches the next batch in the background. |
| `ui/` | Jetpack Compose screens: setup, game, money ladder, lifeline dialogs, game over. |

**Questions.** They're generated five at a time (questions 1-5, 6-10, 11-15), so a full game is three API calls. Each request lists the five difficulty levels (from "very easy, playful" up to "only a true expert") and every question already generated this game, so nothing repeats. The next five are fetched in the background when you reach the third question of the current set. If any question in a reply is unusable, only that one is asked for again.

**Save money (Settings, on by default).** Questions 1-5 and the two lifeline calls use Claude Haiku 4.5, which costs half as much as Sonnet; questions 6-15 use the model you choose.

**50:50** removes two wrong answers at random (no API call, just like the show).

**Phone a Friend.** The game first decides whether your friend actually knows (about 95% chance on question 1, about 46% on question 15) and, if not, whether they guess or admit they've no idea. Claude then writes the friend's 30-second reply in character, sticking to that plan. If the call fails, you get the lifeline back.

**Ask the Audience.** Claude rates how tempting each wrong answer is to an unsure audience (common misconceptions score high); the app then computes the vote, with the correct share falling from ~78% to ~29% as the money rises. If the call fails, the audience still votes with flat guesses.

**Money.** UK ladder from £100 to £1,000,000, safe havens at £1,000 (Q5) and £32,000 (Q10). You can walk away with your current winnings before locking in an answer.

## Tests

`app/src/test/.../GameLogicTest.kt` covers question parsing, ladder maths, lifeline odds and API response handling. Run with `./gradlew test` or from Android Studio.

## Notes

- The API key is stored in the app's private SharedPreferences. That's fine for personal use; for a published app, route calls through your own server instead of shipping keys to devices.
- The models offered in Settings are `claude-sonnet-5-5` (default), `claude-haiku-4-5-20251001` and `claude-opus-5-5`; you can type any other model ID.
- Ideas for extending: a countdown timer for the friend call, "Ask the Host" as a fourth lifeline, sound effects, or a high-score table.
